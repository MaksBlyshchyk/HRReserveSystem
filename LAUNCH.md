# HR Reserve System — Запуск для демонстрації на захисті

## ⚡ Швидкий запуск (3 кроки)

### Крок 1: Передумови (один раз)
```bash
# Встановити Docker Desktop: https://www.docker.com/products/docker-desktop
# Встановити .NET 8 SDK: https://dotnet.microsoft.com/download
```

### Крок 2: Запустити базу даних
```bash
docker compose up -d
```
Чекаємо ~5 сек, поки контейнер Postgres запуститься.

### Крок 3: Запустити додаток
```bash
dotnet run --configuration Release
```

Чекаємо на повідомлення:
```
Now listening on: http://localhost:5000
```

### Крок 4: Відкрити у браузері
```
http://localhost:5000
```

---

## 📋 Для демонстрації на захисті: Сценарій (5–8 хвилин)

1. **Дашборд (30 сек)**
   - Показати статистику: кількість вакансій, кандидатів, заявок
   - Показати дельти за тиждень (動態)

2. **Вакансії (2 хв)**
   - Показати список вакансій з зарплатами
   - (За потреби) додати нову вакансію

3. **Кандидати (1.5 хв)**
   - Показати список, пошук, фільтрацію

4. **Заявки (1 хв)**
   - Показати статуси заявок, зміну статусу

5. **Переспектива (30 сек)**
   - Розповісти про головні функції: синхронізація з Identity, генерування звітів тощо

**Всього: ~5.5 хвилин**

## 🛑 Зупинка

```bash
# Ctrl+C у терміналі з додатком
# Потім:
docker compose down
```

## 🐛 Якщо щось не спрацює

| Проблема | Рішення |
|----------|---------|
| `port 5432 already in use` | `docker compose down` і спробувати ще раз |
| `Database migration error` | Перевірити логи: `docker compose logs postgres` |
| `Додаток не компілюється` | `dotnet restore` + `dotnet build` |
| Браузер не завантажується | Перезапустити `dotnet run` без `--configuration Release` |

## 📝 Демо‑дані

При першому запуску додаток автоматично створює:
- 5 тестових кандидатів
- 5 тестових вакансій (с реальними зарплатами)
- 10 тестових заявок
- Інтерв'ю й оцінки soft skills для демонстрації

(У разі повторного запуску дані зберігаються в базі.)
