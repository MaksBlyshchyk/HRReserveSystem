## 📋 Що треба зробити ТОБ перед захистом

### День 1 (сьогодні): Розгортання на Render
```
1. Переконайся, що весь код закомітлено:
   git add .
   git commit -m "Ready for defense: fix salary types, add Render config"
   git push origin main

2. Перейти на render.com
   Натиснути "New Web Service"
   Вибрати GitHub репозиторій
   Дати команду Render розгортатися

3. Чекати 5-10 хвилин на розгортання
   Отримаєш URL: https://hrreservesystem-xxx.onrender.com
```

### День 2: Перевірка на Render
```
1. Відкрити URL у браузері
2. Залогуватися (форма реєстрації)
3. Перевірити, що дашборд показує дані
4. Проклікати вакансії, кандидатів, заявки
5. Якщо щось не спрацює — перевірити логи на Render Dashboard
```

### День 3: Dry Run (репетиція на виділеному комп'ютері)
```
1. На виділеному комп'ютері відкрити браузер
2. Перейти на URL (наприклад, https://hrreservesystem-xxx.onrender.com)
3. Запустити Google Meet
4. Проклікати сценарій демонстрації (див. нижче)
5. Переконатися, що все працює
```

## 🎬 Сценарій демонстрації (5–8 хвилин)

### 1. Дашборд (30 сек)
- Відкрити http://hrreservesystem-xxx.onrender.com
- Показати метрики: "Кандидатів: 5", "Вакансій: 5", "Заявок: 10+"
- Показати дельти зеленим "За останній тиждень: +2 заявок" та ін.

### 2. Вакансії (2 хв)
- Натиснути "Вакансії" → "List"
- Показати список: "Junior .NET Developer (900–1400 грн)", "HR Analyst (1500–2500 грн)" тощо
- Нагадати про зарплатні вилки: "Це реальні числові дані в PostgreSQL (decimal → numeric)"

### 3. Кандидати (1.5 хв)
- Натиснути "Кандидати" → "List"
- Показати 5 кандидатів з досвідом (Олена, Андрій, Марія, Дмитро, Ірина)
- Клікнути на одного → показати резюме, контакти

### 4. Заявки (1 хв)
- Натиснути "Заявки" → "List"
- Показати статуси: New, Screening, Interview, TestTask, Offer, Hired, Rejected
- Показати, що можна змінити статус

### 5. Раші висновків (30 сек)
- "Система автоматично синхронізує дані з Identity, генерує метрики дашборду"
- "База PostgreSQL надійна й масштабується"
- "Всі функції мають інтеграційні тести (38 тестів проходять)"

**Всього: ~5.5 хвилин**

## 🚨 Якщо щось не спрацює перед захистом

| Проблема | Рішення |
|----------|---------|
| Render не розгортається | Перевірити логи на Render Dashboard → Logs |
| Сторінка не завантажується | Чекаємо ще 30 сек (Render спить на free tier) |
| Дашборд пустий | Зареєструватися й залогуватися; дані з'являться |
| Зарплати показують як текст | Це перетворення, це не помилка (numeric в БД) |
| Google Meet не відкривається | Спробувати в іншому браузері чи переспілатися на виділеному ПК |
